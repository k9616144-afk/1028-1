# 塑膠包材品質客訴智慧分析與改善管理系統

公開網站：https://plas-qms-public.k9616144.chatgpt.site

可直接分享上述網址，訪客不需登入，也不需要啟動本機伺服器。

功能包含客訴案件、MES 批次追溯、品質異常分析、CAPA、8D 報告、品質 KPI 與 SPC 預警。

公開版為示範用途，使用示範資料、內建品質規則與報告範本。案件操作於重新整理後重置；目前未設定 Gemini API 金鑰。

本機開發：安裝 Node.js 後執行 `npm install`、`npm run dev`，再開啟 http://localhost:3000/。

本倉庫保留原始 React、Vite 與 Express 專案；公開版的前端與分析 API 由 Sites 託管。
